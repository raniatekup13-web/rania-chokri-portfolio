# Rania Chokri — Professional Portfolio

Modern responsive portfolio built with HTML, CSS and JavaScript.

## Run in VS Code
1. Open this folder in VS Code.
2. Install **Live Server**.
3. Right-click `index.html` → **Open with Live Server**.

## Personalize
- Add your CV as `assets/Rania-Chokri-CV.pdf` and change the CV button/link if needed.
- Add GitHub links to projects when repositories are ready.
- Replace any project descriptions with exact repository/live-demo details.

## Publish
The site is static and can be deployed on GitHub Pages, Netlify or another static host.
